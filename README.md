## Fitur Utama

### Halaman Beranda
- Hero section dengan tipografi editorial modern
- Animasi angka statistik yang berjalan saat di-scroll
- Efek hitam-putih pada foto tim (`mix-blend-mode: luminosity`)

### Halaman Profil
- Kartu profil 3D yang bisa di-flip 180° saat diklik
- Grafik skill bar yang bergerak otomatis saat di-scroll
- Link ke Instagram & GitHub masing-masing anggota

### Halaman Portofolio & Kontak
- Filter karya berdasarkan kategori (Web Dev / UI/UX / Analisis)
- Data proyek dimuat otomatis dari file JSON menggunakan **AJAX**
- Modal pop-up untuk menampilkan detail proyek
- Form kontak dengan validasi peringatan merah

### Fitur Global (Semua Halaman)
- **Dark/Light Mode Toggle** dengan penyimpanan di `localStorage`
- **Navbar mengambang** dengan efek blur (frosted glass)
- **Responsive design** untuk desktop, tablet, dan mobile
- **Hamburger menu** untuk tampilan mobile
